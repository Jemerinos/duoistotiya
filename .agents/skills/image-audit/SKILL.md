# Historical image audit

## Goal
Ensure every image teaches something specific, is correctly identified, and can be inspected at a useful size. A successful search result or working URL alone is not sufficient.

## Editorial procedure
1. Read the lesson and identify which specific fact, person, place, object, source, or process the image should illuminate.
2. Check the actual image and its file/source page. Verify the depicted subject, approximate date, geography, creator when known, source institution, licence/copyright status, and whether the image is contemporary to the event or a later reconstruction.
3. For maps, inspect date range, borders, orientation, legend, place names, and whether the map's categories fit the lesson. For artworks and reconstructions, do not describe them as photographs or eyewitness evidence.
4. Reject images that are merely keyword matches, duplicate thumbnails, unrelated people/events, misleadingly cropped, or impossible to identify reliably. If uncertain, say so and prefer a more defensible image.
5. Write a concise Russian caption that states what the viewer is seeing and why it matters to this lesson. Never show raw English Wikimedia descriptions or filenames as the pupil-facing caption.
6. Aim for 5–10 distinct, relevant images per lesson where available; do not fill the gallery with near-duplicates or unrelated items to hit a number. If fewer credible images exist, report the shortfall.
7. Keep a working link to the exact source page for each image, including author/licence details when available. Viewer source actions must correspond to the selected image, not a shared unrelated link.
8. Ensure a failed image has a sensible fallback and does not leave a broken or blank viewer. Check keyboard access, click/tap enlargement, mobile layout, and readable captions.
9. If an image cannot be manually inspected in the current environment, mark it as not visually verified. Metadata and API results are not substitutes for visual inspection.

## Output format
For each candidate: lesson/topic, image/source URL, what it actually depicts, relevance to a specific teaching point, date/geography confidence, licence/provenance notes, caption in Russian, and decision (ACCEPT / REJECT / NEEDS HUMAN REVIEW).
Summarize image count per lesson and any unresolved risks. Do not claim a full 182-lesson visual audit if only a sample was checked.
