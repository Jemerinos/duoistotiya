# История вдвоём

Адаптивный веб-курс всемирной истории и истории России: **26 недель, 182 занятия, около 50 минут в день**. Чтение идёт первым; задания в основном выполняются выбором ответа, а не письменными сочинениями.

## Что внутри

- 26 тематических модулей: от методов историка и происхождения человека до мировой истории после 1991 года.
- Страница чтения в стиле учебника: связный рассказ, крупный шрифт, контекст эпохи, опорные факты, понятия простыми словами и примеры повседневной жизни.
- Иллюстрации по теме и галерея из Wikimedia Commons, с подписью, доступными сведениями об авторстве/лицензии и переходом к странице источника.
- Мини-презентация из пяти слайдов, которую можно раскрыть для повторения после чтения.
- Три коротких задания по изображениям: наблюдение, оценка источника и выбор тематической иллюстрации.
- Проверка материала с вариантами ответов и пояснением результата.
- Сохранение выбранных ответов, заметок и отметок о прохождении в браузере.
- Связующие вопросы по книге Юваля Ноя Харари *Sapiens*: когнитивная революция, общие представления, земледелие, деньги, империи, религия и научная революция.
- Дополнительные ссылки на OpenStax, Khan Academy, OER Project, Fordham Sourcebooks и академические работы по истории религии.

## Как устроено занятие

Ориентир — 50 минут: 5 минут на повторение, 20 минут на чтение, 10 минут на разбор карты/изображения/источника, 10 минут на интерактивные вопросы и 5 минут на закрепление.

## Важные учебные оговорки

- *Sapiens* используется как увлекательный каталог больших вопросов, а не как окончательный академический авторитет. Провокационные обобщения Харари, особенно о происхождении религии, общих представлениях и земледелии, нужно проверять по специализированным исследованиям и данным конкретных эпох.
- Задания с выбором ответа помогают закреплять знания и учиться анализировать источники без утомительных ежедневных сочинений. Однако реальные экзамены AP, IB и Cambridge различаются и могут включать короткие письменные ответы, эссе и исследовательские работы. Этот курс закладывает широкую базу, но не заменяет подготовку по действующей спецификации конкретного экзамена.
- Краткие уроки — вводные обзоры, а не исчерпывающая академическая монография. Для спорных тем сравнивайте несколько независимых исследований и первоисточники.
- Исторические картинки загружаются из Wikipedia/Wikimedia Commons и могут быть недоступны при сбоях сети. По возможности карточки показывают название и сведения об источнике; отдельно открывайте страницу файла для проверки контекста и лицензии.

## Запуск

Откройте index.html в браузере. Для загрузки иллюстраций требуется интернет. curriculum.js содержит данные уроков, а index.html — интерфейс приложения.

## Публикация на GitHub Pages

Автоматическая публикация настроена через GitHub Actions в .github/workflows/pages.yml. Workflow проверяет синтаксис JavaScript, структуру курса, количество уроков, HTML ID и наличие интерактивных заданий перед публикацией.

После успешного развёртывания сайт доступен по адресу:

https://jemerinos.github.io/duoistotiya/

## Данные и прогресс

Отметки, выбранные ответы и заметки сохраняются в localStorage текущего браузера. Они не синхронизируются между устройствами. Прогресс новой 182-урочной программы хранится отдельно от прежней короткой версии.
