# История вдвоём

Адаптивное одностраничное веб-приложение для совместного курса истории: 56 занятий на 8 недель, примерно по 30 минут в день.

## Что внутри

- 8 тематических недель: древний мир, античность, Средневековье, Русь и Москва, империи, революции, мировые войны, холодная война и постсоветский мир.
- Мини-презентация из пяти слайдов на каждую тему.
- Три задания по иллюстрациям: наблюдение, интерпретация доказательств и связь картинки с фактами урока.
- Подсказки к заданиям и сохранение ответов отдельно по каждому занятию.
- Поиск запасных изображений в Wikimedia Commons, если в Wikipedia нет миниатюры.
- Таймер на 30 минут.
- Вопросы для обсуждения и ориентир для самопроверки.
- Три проверочных вопроса с обратной связью.
- Сохранение отметок и заметок в браузере.
- Экспорт заметок в Markdown.
- Исторические миниатюры из Wikipedia с запасной иллюстрацией, если изображение недоступно.
- Ссылки на Britannica, Khan Academy, World History Encyclopedia и собрание первоисточников Fordham.
- Адаптация интерфейса для телефона и компьютера.

## Запуск

Откройте index.html в браузере. Для изображений требуется интернет; основная программа курса встроена в файл.

## Публикация на GitHub Pages

В репозитории уже добавлен workflow для автоматической публикации из ветки main.

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Если появится предложенный workflow для Pages, разрешите публикацию. Затем откройте вкладку **Actions** и проверьте выполнение задания **Publish site to GitHub Pages**.
4. После успешной публикации сайт будет доступен по адресу:

   https://jemerinos.github.io/duoistotiya/

Workflow запускается автоматически при новых изменениях в ветке main, а также вручную из Actions через **Run workflow**.

## Что хранится локально

Прогресс и заметки хранятся в localStorage текущего браузера и не синхронизируются между устройствами. Кнопка «Экспорт заметок» позволяет сохранить заметки в Markdown.

## Источники и ограничения

Это учебный прототип, а не финальная академическая публикация. Ссылки на справочные материалы ведут на тематический поиск; они помогают начать проверку, но не являются точными ссылками на доказательство каждого тезиса. Для спорных вопросов сопоставляйте несколько независимых научных источников и первичные документы.

Изображения загружаются через публичный API Wikipedia и могут отсутствовать при сбоях сети. Уроки являются краткими вводными конспектами: перед серьёзным использованием материала следует сверять конкретные утверждения с академическими источниками.
