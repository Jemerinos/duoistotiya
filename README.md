# История вдвоём

Однофайловое адаптивное веб-приложение для совместного курса истории: 56 занятий на 8 недель, примерно по 30 минут в день.

## Что внутри

- 8 тематических недель: древний мир, античность, Средневековье, Русь и Москва, империи, революции, мировые войны, холодная война и постсоветский мир.
- Мини-презентация из пяти слайдов на каждую тему.
- Таймер занятия на 30 минут.
- Вопросы для обсуждения и подсказка для самопроверки.
- Три проверочных вопроса с обратной связью.
- Сохранение отметок и заметок в браузере.
- Экспорт заметок в Markdown.
- Иллюстрации из Wikipedia с заменой на эмодзи, если картинка недоступна.
- Ссылки на Britannica, Khan Academy, World History Encyclopedia и собрание первоисточников Fordham.

## Запуск локально

Откройте index.html в браузере. Сетевое соединение нужно для подгрузки исторических миниатюр; основной интерфейс и уроки находятся в одном файле.

## Публикация на GitHub Pages

1. Откройте репозиторий **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и каталог **/(root)**, нажмите **Save**.
4. Через некоторое время сайт должен появиться по адресу:

   https://jemerinos.github.io/duoistotiya/

Если GitHub предлагает другой способ публикации, следуйте настройкам, показанным в разделе Pages.

## Важное замечание об источниках

Это учебный прототип, а не финальная академическая публикация. Ссылки на справочные материалы ведут на тематический поиск; они помогают начать проверку, но не являются точными ссылками на доказательство каждого тезиса. Для спорных вопросов сопоставляйте несколько независимых научных источников и первичные документы. Исторические иллюстрации подгружаются через публичный API Wikipedia и могут отсутствовать при сбоях сети.

Прогресс и заметки сохраняются только в локальном хранилище текущего браузера и не синхронизируются между устройствами.
