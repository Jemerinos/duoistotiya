### Медиа — открытая проверка
Исходный механизм использует REST summary English Wikipedia и/или поиск файлов Wikimedia Commons. У фонов 26 запросов по неделям. Есть несколько известных слабых мест, требующих проверки в PATCH-002:
- Commons-поиск возвращает несколько кандидатов, но карточки галереи обрезаются до одного результата.
- Источниковая ссылка при открытии главных изображений берётся от общей ссылки `taskPhotoLink`, а не обязательно из данных того конкретного изображения.
- Ошибка изображения может оставить пустое место: текущий основной слой не всегда пытается альтернативный источник после неудачной загрузки.
- Часть подписей генерируется общими шаблонами по типу файла; это не заменяет конкретную подпись, дату/происхождение и релевантность теме.
- Автоматическая выдача поисковика пока не подтверждает историческую актуальность/релевантность картинки.
- Фактическая сетевой доступность каждого результата ещё не тестировалась для 182 занятий.
Эти пункты закрываются только в пределах явно записанных критериев и тестов PATCH-002.
